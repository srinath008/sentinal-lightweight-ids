# Design references

Sentinel's interface adapts the structural patterns in Watermelon UI:

- Landing Page 01: dark hero, product showcase, bento sections and full footer.
  https://ui.watermelon.sh/template/landing-01
- Gridline Dashboard: persistent workspace sidebar, section hierarchy,
  responsive cards, local navigation and workspace status.
  https://ui.watermelon.sh/dashboard/gridline-dashboard

The official registry source for Gridline was inspected; the landing metadata
was fetched from the official catalog and platform repository. Sentinel is a
dependency-free HTML/CSS adaptation rather than the original React template.
The research-specific copy, score chart, incident views and controls are custom.
No stock testimonials, customer logos or invented product metrics were retained.
